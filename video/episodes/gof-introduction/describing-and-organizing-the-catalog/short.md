@art purpose-scope-grid
Twenty three design patterns. Two questions sort every one of them.

@list items="Purpose: create, structure, behave@what does it do|Scope: class or object@classes or objects"
First, what does it do? Create objects, compose them, or divide the work between them. Second, is it about classes or objects?

@words text="Class: fixed at compile time" sub="Object: can change at run time"
Class relationships come from inheritance, so they're fixed when you compile. Object relationships can change while the program runs. Most patterns are object patterns.
