title: When not to use a design pattern

@art indirection-layers
Every design pattern has a price, and the book that named them says so.

@words text="Flexibility = indirection"
A pattern's flexibility usually comes from an extra level of indirection. That can make a design harder to follow, and a little slower.

@quote text="A design pattern should only be applied when the flexibility it affords is actually needed." cite="Design Patterns, Section 1.8"
So, in the Gang of Four's words: a design pattern should only be applied when the flexibility it affords is actually needed.
