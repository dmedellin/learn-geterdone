@words text="The one-time pad" sub="provably unbreakable"
The one-time pad is provably unbreakable. Until you use the key twice.

@words text="Random · as long as the message · never reused"
With a truly random key, as long as the message and never reused, the ciphertext reveals nothing.

@art pad-reuse
Reuse the key, and two messages combine to cancel it out, so both can usually be recovered. That's how the Soviet VENONA traffic was broken.
