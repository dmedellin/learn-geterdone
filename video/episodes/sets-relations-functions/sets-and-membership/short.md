title: Why an empty box inside a box isn't empty

@art empty-boxes
Is a box holding an empty box itself empty? In set theory, no.

@math items="|∅| = 0@empty set;;|{∅}| = 1@set containing"
The empty set has no members, so its size is zero. The set containing the empty set has exactly one member, so its size is one.

@words text="∅ ≠ {∅}"
They're different sets, because a set is nothing but its members, and these two have different members.
