@art empty-inside
The empty set is a subset of every set. Here's why.

@math items="∅ ⊆ A  ⟺  ∀x (x ∈ ∅ → x ∈ A)@means"
Subset means: for every x, if x is in the first set, it's in the second. So the empty set is a subset of A means: if x is in the empty set, then x is in A.

@words text="Nothing to check" sub="the hypothesis is always false"
But nothing is in the empty set. Every one of those conditionals is vacuously true, so the claim holds, for every set.
