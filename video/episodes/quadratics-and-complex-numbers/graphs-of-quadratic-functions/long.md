@chapter The parabola
@title text="Graphs of Quadratic Functions" sub="Quadratics and Complex Numbers" art=thumb
Look at y equals a x squared plus b x plus c, and you can already say a lot about its graph before you plot a single point. Which way it opens, where it crosses each axis, and where its mirror line is.

@words text="f(x) = ax² + bx + c,  a ≠ 0" sub="the graph is a parabola"
A quadratic function is f of x equals a x squared plus b x plus c, with a not zero. If a were zero, the graph would be a straight line. Every quadratic's graph is a curve called a parabola.

@chapter What a does
@art up-down
The coefficient a does two jobs. Its sign sets the direction. If a is positive, the parabola opens upward. If a is negative, it opens downward. b and c slide the curve around, but they never turn it over.

@math heading="At x = 2" items="y = x²  →  4@x squared is at height four;;y = 2x²  →  8@two x squared;;y = (1/2)x²  →  2@one half x squared"
The size of a sets the steepness. At x equals two, x squared is at height four, two x squared is at eight, and one half x squared is at two. So a bigger a, ignoring its sign, gives a narrower curve.

@art three-widths
Otherwise those three parabolas are the same shape. Stretch one, and you get another.

@chapter The intercepts
@art intercepts
The y intercept is f of zero, which is just c. There's exactly one, because a function gives one output for the input zero. The x intercepts are where f of x is zero: the real solutions of the quadratic equation you've been solving all course.

@art crossings-count
So the discriminant counts them before you draw anything. D positive means two crossings. D zero means one point, where the curve touches the axis and turns back. D negative means none, and the parabola sits entirely on one side of the axis.

@chapter The mirror line
@math heading="h = −b/(2a)" items="f(h + t) = f(h) + (2ah + b)t + at²@expand;;2ah + b = −b + b = 0@two a h plus b;;f(h + t) = f(h) + at² = f(h − t)@so f of h plus t"
Every parabola is symmetric about the line x equals minus b over two a. Call that h, and expand f of h plus t. The middle term has two a h plus b, which is minus b plus b, zero. So f of h plus t is f of h plus a t squared, and swapping t for minus t changes nothing.

@art mirror-line
Two points the same distance either side of that line have the same height. And when there are two x intercepts, the axis runs exactly midway between them.

@words text="f(x) = a(x − r)(x − s)" sub="axis (r + s)/2 · y-intercept a·r·s"
So when a quadratic factors, write it as a times x minus r, times x minus s. The roots r and s are right there, the axis is at their midpoint, r plus s over two, and f of zero is a times r times s, with no expanding.

@chapter Sketching one
@math heading="y = x² − 2x − 8" items="x:  −2   −1   0   1   2   3   4@from minus two;;y:   0   −5  −8  −9  −8  −5   0@the heights;;axis  x = 1@about x equals one"
Take y equals x squared minus two x minus eight. a is one, so it opens upward. Make a table from minus two to four, and the heights go zero, minus five, minus eight, minus nine, then back up: minus eight, minus five, zero. The table is symmetric about x equals one.

@math heading="y = −x² + 4x − 3" items="opens downward,  y-intercept (0, −3)@opens downward;;−(x − 1)(x − 3)  →  x = 1, 3@factoring;;axis x = 2,  f(2) = 1  →  highest point (2, 1)@midway"
Now y equals minus x squared plus four x minus three. a is minus one, so it opens downward, and the y intercept is zero, minus three. Factoring gives minus, x minus one, times x minus three, so it crosses at one and three. The axis is midway, at two, and f of two is one. So the highest point is two, one.

@chapter Sample both sides
@art one-arm
Find the axis before choosing x values. If the axis is at minus four, and you plot zero, one, two and three, you get four points from one arm. They look like a line bending, and the picture is unrecognisable. Take values either side, and the matching heights check your arithmetic for free.

@chapter Where people slip
@list heading="Common slips" items="Deciding the direction from c@The first|Sampling on one side of the axis@The second|Calling no x-intercept a broken graph@The third"
The first slip is deciding the direction from c, or from the roots. x squared minus a hundred still opens upward. The second is sampling only one side of the axis. The third is calling a parabola with no x intercept broken. y equals x squared plus one is a perfectly ordinary function. It just never takes the value zero.
