@art up-down
Which way does a parabola open? Only one number decides.

@words text="a > 0 opens up    a < 0 opens down"
In y equals a x squared plus b x plus c, it's a. Positive a opens upward. Negative a opens downward.

@math items="y = x² − 100  →  opens up@minus a hundred;;y = −x² + 100  →  opens down@plus a hundred"
So x squared minus a hundred still opens upward, and minus x squared plus a hundred opens downward. b and c only slide the curve around.
