@chapter The question
@title text="The Square Root Property" sub="Quadratics and Complex Numbers" art=thumb
x squared equals twenty five. What's x? If you said five, you've found half the answer. The other half is where most mistakes in this course start.

@art square-tile
The square root sign names one number, the non-negative one. Root twenty five is five. Not minus five, and not plus or minus five. The second solution comes from the property, not from the symbol.

@chapter The property
@list heading="x² = k" items="k > 0: two solutions, √k and −√k@positive|k = 0: one solution, x = 0@is zero|k < 0: no real solution@negative"
Here's the full rule. If k is positive, x squared equals k has two real solutions, root k and minus root k. If k is zero, the only solution is zero. And if k is negative, there's no real solution at all.

@art mirror-dots
For positive k, you can see why there are two. x squared minus k factors as x minus root k, times x plus root k, by the difference of squares. The zero product property splits that into two different numbers.

@art collapsed-pair
When k is zero, the same factorisation reads x times x equals zero. The two brackets have collapsed onto each other, so there's one solution.

@art parabola-above
And when k is negative, no real number works, because every real number squared is zero or positive. It isn't that the answer is hard to find. There isn't one among the real numbers.

@chapter Plus or minus
@words text="x = ±√k" sub="x is √k, or x is −√k"
The plus or minus sign is notation, not an operation. It's short for a sentence: x is root k, or x is minus root k. Writing it saves a line. Forgetting it loses a solution, and the answer that's left looks complete.

@math heading="Why √(x²) isn't x" items="√((−3)²) = √9 = 3@at minus three;;√(x²) = |x|@absolute value;;|x| = √k  →  x = ±√k@two cases"
Square rooting both sides hides a real difficulty. The root of x squared isn't x. At minus three, the left side is root nine, which is three, but x is minus three. So the root of x squared is the absolute value of x, and an absolute value equation splits into two cases.

@chapter Isolate the square
@math heading="3x² − 75 = 0" items="3x² = 75@add seventy five;;x² = 25@divide both sides;;x = 5  or  x = −5@five or minus five"
The property is stated for x squared equals k, so clear everything else first. Three x squared minus seventy five equals zero. Add seventy five, then divide both sides by three, to get x squared equals twenty five. So x is five or minus five.

@chapter The shifted form
@art shifted-pair
The property doesn't care what's being squared. If x minus h, squared, equals k, then x minus h is plus or minus root k, so x is h plus or minus root k. Every completed square ends in this form.

@math heading="(x − 4)² = 20" items="x − 4 = ±√20@plus or minus root twenty;;√20 = √(4 · 5) = 2√5@four times five;;x = 4 ± 2√5@four plus or minus;;(4 + 2√5 − 4)² = (2√5)² = 20@check the first"
Take x minus four, squared, equals twenty. So x minus four is plus or minus root twenty, and root twenty is root of four times five, two root five. The solutions are four plus or minus two root five. To check the first, the fours cancel, and two root five squared is twenty.

@words text="2√5, not a decimal" sub="simplify the radical, keep it exact"
Simplify the radical, and leave it as a radical. Two root five is a number. Swap it for a rounded decimal, and the answer is no longer a solution of the equation.

@chapter Where people slip
@list heading="Common slips" items="Writing only the positive root@The first|Writing √9 = ±3@The second|Rooting each term separately@The third"
The first slip is writing only the positive root, or adding the sign too late. x plus two, squared, equals nine has solutions one and minus five. Write plus or minus one at the end, and one is wrong. The second is writing root nine as plus or minus three. The symbol gives one value. The third is rooting each term of a sum separately.

@math heading="x² + 9 = 25" items="x + 3 = 5  ✗@you can't conclude;;x² = 16  →  x = ±4@sixteen"
From x squared plus nine equals twenty five, you can't conclude x plus three equals five. The right way gives x squared equals sixteen, so x is plus or minus four. The shortcut's answer, two, fails: four plus nine is thirteen.
