title: Near support is not a trading rule
---

@art true-false
Buy near support. Sounds like a rule. A program can't run it.

@words text="Every condition: true or false"
A real rule resolves to true or false from known bar data and explicit parameters. Near support needs a number, a boundary and a bar timing.

@art filter-trigger-exit
Then split it into a filter, a trigger and an exit, so anyone can reproduce every event.
