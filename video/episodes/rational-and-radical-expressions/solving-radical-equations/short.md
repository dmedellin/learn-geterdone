title: An equation with no solution that squaring solves

@art never-negative
Square root of x plus one equals minus three. Squaring says x is eight.

@math items="x + 1 = 9  →  x = 8@x plus one equals nine;;√9 = 3,  not −3@root nine"
Square both sides, and x plus one equals nine, so x is eight. But check it. Root nine is three, not minus three.

@words text="No solution" sub="a principal square root is never negative"
A principal square root is never negative, so there was no solution from the start. Squaring just can't tell.
