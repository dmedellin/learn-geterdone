You shorten a critical activity by four days. The project finishes one day sooner.

@math items="C − 1:  12 → 11@One day off;;C − 4:  still 11@Four days off"
In the lesson's project, C is critical. One day off C takes the project from twelve to eleven. Four days off, still eleven.

@words text="A second path drew level"
After one day, a different chain, A, G, H, I, is just as long, and C isn't on it. So the next day off C buys nothing.
