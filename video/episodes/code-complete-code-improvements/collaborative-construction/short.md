@art one-step
At IBM, a code inspection found a defect in three and a half hours.

@math items="inspection: 3.5 hours@three point five;;testing: 15 to 25 hours@fifteen to twenty five"
That's three point five hours by inspection. Testing took fifteen to twenty five hours for each one, as the book reports it.

@words text="Defect and cause, together"
The reason is that an inspection finds the defect and its cause together. A test finds a symptom, and someone still has to debug it.
