title: A random variable is not random
---

@words text="Neither random nor a variable"
A random variable is neither random nor a variable. So what is it?

@art function-arrows
It's a function. It gives each outcome one number, like the sum of two dice, or the number of heads in three flips.

@words text="X : S → ℝ"
The function itself is completely fixed. What's random is which outcome happens. Keep that straight and the rest gets easier.
