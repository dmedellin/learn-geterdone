title: The absolute value trick that only works one way
---

@art inflate-pair
Write an absolute value as a sum, then maximise it. Watch it explode.

@math items="|x| = x⁺ + x⁻@their sum;;minimise 2|x| + 5y:  40/3 both ways@forty over three;;maximise:  original 36,  rewrite unbounded@unbounded"
Split x into two parts and write the absolute value as their sum. Minimised, the rewrite matches: forty over three. Maximised, the original is thirty six, and the rewrite is unbounded, because both parts climb together.

@words text="Which way is the variable pushed?"
So always ask which way the optimiser pushes your new variable.
