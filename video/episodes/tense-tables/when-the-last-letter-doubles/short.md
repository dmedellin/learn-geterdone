@art coin-balance
The doubling rule most books print is right only about half the time.

@math items="double every one  →  49.3%@forty-nine;;double if the last part is strong  →  91.7%@ninety-one"
On two hundred and seventeen verbs, double every one, and you're right forty-nine point three percent of the time. Double only when the last part is strong, and it's ninety-one point seven.

@words text="adMIT → admitting · VISit → visiting"
So say the word. Admit doubles. Visit doesn't.
