@art sold-broken-chair
Two teams say seat. One evening, a broken chair gets sold.

@words text="seat: sellable place · seat: physical chair"
To the box office, a seat is a place in a performance that can be sold. To the venue team, it's a chair that can break. Same word, different ideas. Evans calls that a false cognate.

@art context-boundary
So draw a line around each model, consistent inside, and translate across it.
