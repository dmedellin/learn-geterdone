@art first-subdomain
Merging two teams' models? The core is exactly where not to start.

@words text="Small · duplicated · generic · already translated"
Evans's first step is a Shared Kernel built on something small, duplicated in both, generic, and ideally already translated.

@art process-first
That first merge isn't about the model. It sets up the process: shared code, naming, weekly integration, and tests. The core comes later, once the people are ready.
