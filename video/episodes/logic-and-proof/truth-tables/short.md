@art doubling-tree
A truth table is never wrong. It just gets enormous.

@math items="3 variables  →  8 rows@three variables;;10 variables  →  1024 rows@ten variables;;20 variables  →  over a million@twenty"
Every variable doubles the rows. Three variables give eight rows. Ten variables give one thousand and twenty four. Twenty give over a million.

@words text="2ⁿ rows" sub="complete, but exponential"
So a table answers every question about a formula, always correctly. The catch is size, two to the n rows.
