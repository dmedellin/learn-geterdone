title: The ground is wet, so it rained?
---

@art two-sources
The ground is wet, so it rained. That argument is invalid.

@math items="p → q,  q  ⊬  p@if it rains;;p = F, q = T@sprinkler"
The premise is: if it rains, the ground is wet. But a sprinkler wets the ground too. No rain, wet ground. Both premises true, conclusion false.

@words text="Affirming the consequent"
It's called affirming the consequent. It treats if as if and only if.
