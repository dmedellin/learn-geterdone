title: Why logic bans "This sentence is false"
---

@art paradox-loop
One sentence breaks logic: this sentence is false.

@words text="True → then it's false" sub="False → then it's true"
If it's true, then what it says holds, so it's false. If it's false, then it's true. No truth value fits.

@words text="True or false, but not both"
So logic only works with propositions, sentences with exactly one truth value. Sentences that talk about their own truth are shut out, because they break the two valued system.
