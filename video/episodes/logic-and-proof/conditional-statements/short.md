title: Why a false "if" makes the whole statement true

@art empty-ring
Every unicorn in this room is purple. That's true.

@math items="T F  →  F@broken in exactly one case;;F T  →  T@false hypothesis;;F F  →  T@whatever"
If p then q is a promise, and it's broken in exactly one case: p true and q false. With a false hypothesis, nothing is promised, so the conditional is true, whatever q is.

@words text="Vacuously true"
No unicorn is here to be a counterexample, so the statement is vacuously true.
