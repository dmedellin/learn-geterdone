A long, careful name can still hide what your code is for.

@words text="scanArrayForZeroRun" sub="an array, zeros, a run"
Take scan array for zero run. It's long, but it names the mechanism: an array, zeros, a run. A client still has to know that a zero means a free seat.

@words text="canSeatTogether(partySize)"
Now ask the clerk's question instead. Can seat together, given a party size. That name states the effect and the purpose, in the box office's own words.
