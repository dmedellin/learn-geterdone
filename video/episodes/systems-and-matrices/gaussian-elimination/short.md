@art dead-row
See this row while row reducing? Stop. The system has no solution.

@math items="[ 0  0  0 | 4 ]@zero, zero, zero, four;;0x + 0y + 0z = 4@zero x"
The row zero, zero, zero, four says zero x plus zero y plus zero z equals four. No triple satisfies that. Once this row appears, the question has been answered.

@words text="Stop reducing" sub="a tidy matrix can still mean nothing"
Keep reducing anyway, and you'll get a tidy matrix that means nothing. And tidy matrices are persuasive.
