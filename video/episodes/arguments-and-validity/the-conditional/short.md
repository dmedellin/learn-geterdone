title: Only if runs the opposite way to if

@art only-if-gate
You may vote if you're registered. You may vote only if you're registered. They're different rules.

@words text="vote only if registered" sub="v → r"
Only if names the requirement. Voting only if registered means voting needs registration. So if you vote, you're registered.

@words text="vote if registered" sub="r → v"
Plain if names what's enough. Voting if registered means registration lets you vote. Same words, opposite arrows.
