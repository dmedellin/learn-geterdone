title: Can you be sure you see, if nothing is there?

@art ashtray-pipe
Can you be sure you see an ash tray if none is there?

@words text="I am sure that I think I see an ash-tray"
Descartes said: I'm not sure the ash tray is there, but I'm sure I think I see it.

@words text="To see is to see something."
Merleau-Ponty says those can't be pulled apart. If I see, in the full sense, something is there. To see is to see something.

@words text="certain only so long as actual sight is equally so"
Without the thing, the thought of seeing is a mere impression. It's certain only so long as actual sight is equally so.
