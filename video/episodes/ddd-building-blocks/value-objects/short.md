@words text="1 change · 2 surprised"
One customer moved her bakery pickup, and two other customers moved with her.

@art shared-name
Three orders shared one pickup slot, and the slot was changed in place. Everyone holding it saw the change.

@art own-copies
Evans's rule: a value can be shared only if it's immutable. To change it, replace it with a new one.

@words text="A mutable value must not be shared."
And if a value must be mutable, it must not be shared.
