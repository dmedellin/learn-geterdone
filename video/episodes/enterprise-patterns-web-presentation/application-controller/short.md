@art wizard-steps
Do you need an Application Controller? One question tells you.

@words text="Who picks the next screen?"
Ask who decides which screen comes next. If the application decides, as in a wizard, you want one, to hold the flow in one place.

@art user-led
If the user decides, opening screens in nearly any order, there are no rules to hold, and you don't need one.
