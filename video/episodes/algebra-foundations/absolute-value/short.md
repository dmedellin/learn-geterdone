title: The absolute value of x is three. What is x?
---

@words text="|x| = 3"
If the absolute value of x is three, what's x? There are two answers.

@art two-points
Absolute value is distance from zero. Three steps right of zero is three. Three steps left is minus three.

@math items="x = 3   or   x = −3@three, or minus three"
So x is three, or minus three. Drop the second, and you've lost half the answer.

@words text="|x| = −1:   no solution"
And if it equals minus one? No solution. A distance is never negative.
