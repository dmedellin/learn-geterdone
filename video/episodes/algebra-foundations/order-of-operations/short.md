@words text="−3² = ?"
Minus three squared. Is it nine, or minus nine?

@art exponent-base
An exponent grabs only the smallest thing written right before it. Here, that's the three. The minus sign waits outside.

@math items="−3² = −(3²) = −9@is minus nine;;(−3)² = 9@brackets"
So minus three squared is minus nine. If you want nine, you need brackets around the minus three.

@words text="Substitute with brackets"
That's why, when you put a negative number in for a letter, you always write brackets round it.
