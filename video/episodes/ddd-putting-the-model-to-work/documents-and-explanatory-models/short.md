@words text="Is your design doc still alive?"
Here's a one-minute test for whether your design document is still alive.

@art text-with-sketches
Read it against the team. Are its words the ones people speak now, and the ones in the code?

@art stale-page
Where speech and code agree and the document says something else, that's a stale term. A bike-share's year-old document had three.

@quote text="A document shouldn't try to do what the code already does well." cite="Evans, Domain-Driven Design, Chapter 2"
And a document shouldn't try to do what the code already does well.
