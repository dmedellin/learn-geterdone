@art walls
This curve rises toward the line above it. And it can never reach it.

@math items="y′ = y·(1 − y)@y times one minus y;;y = 1:   slope 0, a solution@At y equals one"
The equation is y prime equals y times one minus y. At y equals one the slope is zero for every t, so that line is a solution itself.

@words text="one point, one solution"
Through each point there's exactly one solution. The line is already there, so the curve can't touch it.
