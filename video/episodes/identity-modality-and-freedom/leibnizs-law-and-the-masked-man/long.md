@chapter The puzzle
@title text="Leibniz's Law and the Masked Man" sub="Identity, Modality and Freedom" art=thumb
I know that my father is here. I don't know that the masked man is here. But the masked man is my father. Does that refute one of the most basic laws of identity?

@words text="If a is b, a and b share every property" sub="Leibniz's law"
Leibniz's law says that if a and b are the same thing, then whatever is true of a is true of b. So here's the argument. My father has a property the masked man lacks, being known by me to be here. So they aren't the same man. But they are. Something has gone wrong.

@chapter The model
@art masked-figure
Let f say, my father is here, and m say, the masked man is here. At the actual world, world one, both are true. The man in the mask is my father.

@math heading="Two worlds" items="w1:  f true,  m true@world one itself;;w2:  f true,  m false@At world two"
Now read the box as, it is known that, and draw arcs from world one to the worlds compatible with what I know. There are two: world one itself, and world two. At world two my father is here, but the man in the mask isn't, since for all I know, the masked man is a stranger.

@chapter Evaluating
@math heading="At w1" items="□f:  true at w1 and w2,  so true@Box f;;□m:  fails at w2,  so false@Box m;;f ↔ m:  true@f if and only if m;;□f ↔ □m:  false@the boxed versions"
Box f is true at world one, because f holds at both worlds it sees. Box m is false, because m fails at world two. And f if and only if m is true at world one, since both are true there. So two sentences are equivalent, and the boxed versions differ.

@art box-looks-away
That's the whole of the masked man. Substituting equivalents inside a box fails, because a box consults worlds where the equivalence need not hold.

@chapter Outside the box
@art swap-arrows
Outside the box, nothing fails. From f if and only if m at world one, you can swap f and m in any context that looks only at world one: a conjunction, a negation, a conditional.

@art single-world
And with a single world, the box has only that one world to look at. f and m agree there, so box f if and only if box m is true. Substitution inside the box is harmless when the box has nothing to disagree about.

@words text="Opaque context" sub="swapping things that agree at the actual world changes the whole"
A context is opaque when swapping two sentences, or two names for one thing, that agree at the actual world can change the value of the whole. A box is opaque whenever the worlds it looks at can disagree.

@chapter The same shape with necessity
@art eight-planets
The same shape appears with necessity. The number of planets is eight. Eight is necessarily even. But it doesn't follow that the number of planets is necessarily even, since there are worlds where the planets are seven. Same model, with the arcs read as necessity instead of knowledge. The computation doesn't change at all.

@chapter What survives
@art two-labels
What survives for Leibniz is a point about what the law covers. It speaks of properties of the man. Being known to be here isn't one of them, because it changes with the description. That reply isn't free. It commits you to a distinction between properties of things and properties under descriptions, and some philosophers resist it.

@chapter Where people slip
@list heading="Common slips" items="Thinking the masked man refutes Leibniz's law@The first|Thinking substitution fails in every context@The second|Treating it as a quirk of talk about knowledge@And the third"
The first slip is thinking the masked man refutes Leibniz's law. The law was never applied to anything it covers. The second is thinking substitution fails in every context. Outside a box, it holds. And the third is treating the failure as a quirk of talk about knowledge. Any operator that quantifies over worlds behaves this way.

@chapter Try it
@words text="□f ↔ □m" sub="on the first model, then on one world"
Try it with the masked man model. Evaluate box f and box m at world one, then box f if and only if box m. Then delete world two, and evaluate them again. Say why the substitution now works.
