@art three-trees
Same fifteen keys. One search tree has height fourteen. Another has height three.

@math items="sorted order:  height 14@sorted order;;shuffled:  height 6@shuffled;;middle first:  height 3@middle first"
Insert them in sorted order and you get a path, height fourteen. Shuffled, height six. Middle first, then the middle of each half, height three.

@words text="The order decides the shape"
The keys didn't change. Only the order they arrived in did.
