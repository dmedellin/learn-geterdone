title: Independent set and vertex cover are the same problem

@art set-complement
Find an independent set, and you've found a vertex cover for free.

@words text="S independent ⟺ V − S covers"
If no edge has both ends in S, then every edge has an end outside S. So everything outside an independent set touches every edge.

@math items="five-cycle:  α = 2,  τ = 3@largest independent set;;α + τ = 5 = n@add to five"
On the five cycle, the largest independent set has two vertices, the smallest cover three. They add to five, the number of vertices.
