@art two-circuits
Two circuits, wired completely differently, can do exactly the same job.

@math items="(p ∧ q) ∨ (p ∧ r)@three gates;;p ∧ (q ∨ r)@two gates"
One uses three gates. The other uses only two gates. Check all eight rows, and their outputs match every time.

@words text="The state is the function"
That's functionalism. Pain is whatever plays the pain role, in neurons or in silicon, so the same state can be built many different ways.
