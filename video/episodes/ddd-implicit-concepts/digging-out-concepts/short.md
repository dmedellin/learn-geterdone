Librarians say recall. The developers say recall. The code has no name for it at all.

@art doubly-strong
Evans calls a word the experts use, and the design doesn't contain, a warning sign. When the developers use it too, the warning is twice as strong.

@art listen-words
So listen. A word nobody can find in the code is a lead to a concept the model is missing.
