@art root-and-factor
Find one root of a polynomial, and you've found a factor for free.

@math items="f(c) = 0  ⟺  (x − c) is a factor@if and only if"
That's the factor theorem. f of c is zero if and only if x minus c is a factor of f.

@math items="f(−1) = −2 − 3 + 8 − 3 = 0@f of minus one;;(x + 1) is a factor@x plus one"
For two x cubed minus three x squared minus eight x minus three, f of minus one is zero. So x plus one is a factor, and dividing it out leaves a quadratic.
