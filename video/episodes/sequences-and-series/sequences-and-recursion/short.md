@art many-starts
Double the last term. That rule describes infinitely many different sequences.

@math items="5, 10, 20, 40, …@five, ten;;3, 6, 12, 24, …@three, six;;0, 0, 0, 0, …@zero, zero"
Five, ten, twenty, forty fits it. So does three, six, twelve, twenty four. So does zero, zero, zero.

@words text="a₁ = 5,   aₙ = 2aₙ₋₁" sub="a starting term and a rule"
The rule says how to move, not where to start. Add a one equals five, and now there's exactly one sequence.
