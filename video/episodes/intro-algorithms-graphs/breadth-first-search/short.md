@art hexagon
Breadth first search always gets distances right, but not always the same tree.

@art layers
Search a hexagon from vertex one. The far vertex, four, is at distance three either way round, and it takes parent three, because three leaves the queue first.

@words text="edge 6–1 first → parent 5" sub="distance still 3"
Type the edge from six to one first, and its parent becomes five. The distance is still three.
