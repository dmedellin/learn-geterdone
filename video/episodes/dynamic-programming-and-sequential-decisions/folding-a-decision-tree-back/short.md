@art useless-signal
Perfect information is worth twenty here. This signal is worth exactly nothing.

@words text="P(g | up) = P(g | down) = ½"
Each reading is equally likely whether things go up or down. So the posterior equals the prior.

@art signal-branches
And a signal is only worth something when it changes what you do. Here you go after either reading, so its value is zero.
