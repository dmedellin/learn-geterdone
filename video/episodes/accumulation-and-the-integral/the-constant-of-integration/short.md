title: The constant is not the value you were given

@art height-vs-constant
If y of one is five, is the constant five? No.

@math items="y = t² + C@t squared plus C;;1² + C = 5@one squared;;C = 4@So C"
The rate is two t, so the family is t squared plus C. Put in one: one squared plus C is five. So C is four, not five.

@words text="C = value − F(t₀)"
The value is a height on the curve. The constant is that height, minus F at that place.
