@art binary-fraction
Add point one to itself ten times. Do you get one?

@words text="0.9999999999999999"
Not in a Java double. You get point nine nine nine, and so on. Point one has no exact binary form, so the double holds the nearest fraction, and the tiny errors add up.

@art cents-jar
For money, count in whole cents instead. Ten cents, ten times, is exactly a hundred.
