@words text="NP = not polynomial?"
NP does not mean not polynomial. Most people get this wrong.

@art solve-vs-check
NP is the set of problems where a proposed answer can be checked quickly, in polynomial time. The name comes from an older definition, nondeterministic polynomial.

@art nested-circles
And every problem you can solve quickly, you can also check quickly. So P sits inside NP. Whether they're equal is still open.
