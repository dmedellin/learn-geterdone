@art empty-step
Your routine compiles, passes its tests, and still skips a step. Would you know?

@art comments-to-code
Write the routine first as plain English comments. Then fill in the code beneath each one.

@words text="A comment with nothing beneath it"
Now a step you forgot shows up as a comment with nothing beneath it. A promise the routine doesn't keep, in plain sight.
