title: The best reason to write a routine isn't duplication

@art hide-behind-name
Most people write a routine to avoid repeating code. That's not the main reason.

@words text="Reduce complexity"
Steve McConnell calls reducing complexity the single most important reason. Put a detail behind a good name, and you can stop thinking about it.

@art one-line-guard
So even code you use once can deserve a routine. And even one line. Small operations tend to grow.
