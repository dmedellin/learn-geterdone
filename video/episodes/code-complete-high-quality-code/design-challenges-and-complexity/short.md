@art hoses
Every connection between your modules is a hose full of water.

@words text="Pull one module out"
That's Steve McConnell's image. Now try to pull one module out, to use somewhere else, and see how wet you get.

@art layered-modules
So allow communication on a need to know basis. Layer the design, and keep it free of cycles.

@words text="Manage complexity"
Because software's primary technical imperative is managing complexity.
