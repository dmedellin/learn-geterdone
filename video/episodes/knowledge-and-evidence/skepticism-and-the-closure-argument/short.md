@art shared-conditional
The skeptic and Moore use the same premise, and reach opposite conclusions.

@words text="If I know I have hands, I know I'm not a brain in a vat."
Both accept this: if I know I have hands, I know I'm not a brain in a vat.

@words text="Skeptic: ¬b, so ¬h · Moore: h, so b"
The skeptic says, I don't know I'm not envatted, so I don't know I have hands. Moore says, I know I have hands, so I know I'm not envatted. Both arguments are valid.
