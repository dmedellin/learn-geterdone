@art sorted-path
Insert twelve sorted keys, and a search tree becomes a path.

@art key-priority
That path has height eleven. Now give each key a random priority, and keep the tree a heap on priorities as well as a search tree on keys.

@words text="height 11 → 5" sub="same tree for any insertion order"
Only one such tree exists. So sorted or shuffled, you get the same treap, here of height five.
