@words text="S = C + rC" sub="solve for C"
C appears twice. How do you get it alone?

@art factor-out
Factor it out. S equals C times one plus r. Don't forget the one: C on its own is one times C.

@math items="C = S/(1 + r)@C equals S over;;1 + r ≠ 0@isn't zero"
Now divide. C equals S over one plus r, as long as one plus r isn't zero.

@art forbidden-divisor
The forbidden value is r equals minus one, not zero. Read the divisor, not the letter.
