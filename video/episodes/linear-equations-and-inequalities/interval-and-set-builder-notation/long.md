@chapter Why new notation
@title text="Interval and Set-Builder Notation" sub="Linear Equations and Inequalities" art=thumb
Every inequality you've solved has had a set of numbers as its answer. Writing that set as an inequality works, until the set comes in two pieces. Two standard notations fix that, and both are exact.

@chapter Interval notation
@art brackets-dots
Interval notation names the two ends, and says whether each one is included. A square bracket includes its endpoint. A round bracket excludes it. On the number line, a square bracket is a filled dot, and a round bracket is a hollow one.

@math heading="For a ≤ b" items="[a, b]:  a ≤ x ≤ b@both ends;;(a, b):  a < x < b@neither end;;[a, b) and (a, b]:  one end each@one end each"
So the square brackets a, b means every x from a to b, both ends included. Round brackets a, b means neither end is included. And you can mix them, including one end each. That's ordinary, not a mistake. At least two and less than five is exactly a square bracket at two and a round one at five.

@art infinity-end
Unbounded ends use infinity and minus infinity, and they always get a round bracket. Infinity is a direction, not a number. There's nothing there to include. So it's square bracket three, infinity, round bracket. And the whole line is minus infinity to infinity, round at both ends.

@chapter Set-builder notation
@words text="{ x ∈ ℝ : x ≥ 2 }" sub="the set of real numbers x such that x ≥ 2"
Set-builder notation states the condition a number must satisfy. Read this as: the set of real numbers x, such that x is at least two. The colon means such that, and a vertical bar does the same job. The little curly e means is an element of.

@art sieve
Naming where the numbers come from matters. The real numbers x with two at most x at most five is an interval. But the integers with the same condition are just four numbers: two, three, four and five. Set-builder can also describe sets no interval can, like the rational numbers.

@chapter One set, four ways
@math heading="One set" items="−1 ≤ x < 3@as an inequality;;[−1, 3)@as an interval;;{ x ∈ ℝ : −1 ≤ x < 3 }@in set builder;;filled dot at −1, hollow dot at 3@on the number line"
Here's one set written four ways. As an inequality, minus one is at most x, which is less than three. As an interval, square bracket minus one, three, round bracket. In set builder, the real numbers x with that same condition. And on the number line, a filled dot at minus one, a hollow dot at three, shaded between.

@chapter Two pieces
@art union-pieces
Now two pieces. x at most minus two, or x at least five. In interval notation that's a union: minus infinity to minus two, with a square bracket at minus two, union square bracket five to infinity. That union sign is the or from compound inequalities.

@chapter Forms that describe nothing
@list heading="Forms that describe nothing" items="[3, ∞]  →  write [3, ∞)@square bracket on infinity|(4, 4)  →  ∅, but [4, 4] = { 4 }@round four, four|x = [2, 5)  →  write x ∈ [2, 5)@x equals an interval"
Some forms describe nothing. A square bracket on infinity is wrong: write it round. Round four, four is empty, but square four, four is the set holding just four. And x equals an interval sets a number equal to a set. Write x is an element of the interval instead.

@art wrong-order
Order matters too. Five, two is not another way of writing two, five. Read as a condition, it asks for numbers at least five and at most two, and there are none. Interval notation names the smaller end first, and nothing on the page warns you when the order has gone.

@art empty-vs-zero
The empty set is written as a slashed circle, or empty braces. It isn't zero, and it isn't the set containing zero. That set has one element. The empty set has none. If an inequality has no solutions, writing zero would claim that zero is a solution.

@chapter Reading one back
@words text="(−∞, −2] ∪ [5, ∞)" sub="{ x ∈ ℝ : x ≤ −2 or x ≥ 5 }"
Read that union back. Two pieces. The left runs for ever downward and stops at minus two, which it includes. The right starts at five, includes it, and runs for ever upward. Nothing strictly between minus two and five belongs to it.

@words text="{ 5, −3 }" sub="a set small enough to list is listed"
And a set small enough to list is just listed, like five and minus three, the answer to an absolute value equation. Interval notation can reach it, but clumsily. The set decides which notation is readable.

@chapter Try it
@words text="x < −2 or x ≥ 3" sub="write it as an interval, then in set-builder"
For practice, take x less than minus two, or x at least three. Write it in interval notation, choosing each bracket carefully. Then write it in set builder notation, and say aloud what each one includes.
