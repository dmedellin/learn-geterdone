@words text="|x + 4| = −2" sub="solve it?"
The absolute value of x plus four equals minus two. What's x?

@art distance-two
Absolute value is a distance from zero. And a distance is never negative.

@art no-solution-check
Split it anyway and you get minus six and minus two. Check them. Both give two, not minus two.

@words text="No solution" sub="and that's the complete answer"
So there's no solution, and saying so is the complete answer.
