@art two-levels
What if a new kind of customer was just a new row, not a new class?

@words text="BorrowerCategory: a row a superuser edits"
That's a knowledge level: objects that describe how other objects may behave. In the lesson's library, a new visitor category touches one module, the table, and no code is written.

@art amnesty-new-rule
But a new kind of rule, like an exam time amnesty, is still new code. A knowledge level only absorbs the changes it was built for.
