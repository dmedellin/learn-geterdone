title: A £1,000 machine adds £1 a day, and never more
---

@art machine-corpse
A thousand pound machine can make a mountain of yarn. It still adds only a thousand pounds.

@math items="£1,000 / 1,000 days = £1 a day@a pound a day"
If it lasts a thousand days, it passes a pound a day into the product, as it wears out.

@words text="Constant capital: carries value over, adds none"
Marx calls it constant capital. It passes on exactly the value it loses. Only labour-power, variable capital, adds new value.
