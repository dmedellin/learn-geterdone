@chapter The question
@title text="Graphing a Linear Equation" sub="Lines, Functions and Graphs" art=thumb
An equation with one unknown usually has one answer. An equation with two unknowns has infinitely many. So what does it even mean to solve one? You draw all of its answers at once.

@words text="ax + by = c" sub="a and b not both zero"
A linear equation in two variables is one you can write as a x plus b y equals c, where a and b aren't both zero. Its graph is always a straight line, and every straight line is the graph of one.

@words text="xy = 6     y = x²" sub="two variables, not linear"
What makes it linear? x and y each appear to the first power only. Never multiplied together, never under a root or in a denominator. So x y equals six and y equals x squared have two variables, but they aren't linear, and their graphs aren't lines.

@chapter The table method
@art table-to-points
The first method never fails. Choose a value for x, substitute it, solve for y, and write down the pair. Then do it again. It needs nothing new, so it's the one to fall back on whenever a shortcut isn't there.

@math heading="y = −2x + 1" items="x = −1:  −2(−1) + 1 = 3   →  (−1, 3)@minus one;;x = 0:  −2(0) + 1 = 1   →  (0, 1)@x is zero;;x = 1:  −2(1) + 1 = −1   →  (1, −1)@x is one;;x = 2:  −2(2) + 1 = −3   →  (2, −3)@x is two"
Take y equals minus two x plus one. When x is minus one, y is three. When x is zero, y is one. When x is one, y is minus one. And when x is two, y is minus three.

@art dots-in-line
Plot those four points and they fall in a line. Each step of one to the right drops y by two. That steady drop has a name, slope, and it gets its own lesson.

@chapter The intercept shortcut
@art intercepts
The fastest two points are usually the intercepts. The x intercept is where the line meets the x axis, and you find it by setting y to zero. The y intercept is where it meets the y axis, and you find it by setting x to zero.

@words text="On the x-axis, y = 0"
That rule is easy to say backwards, so tie it to the picture. Every point on the x axis has height zero. So to land on the x axis, you set y equal to zero, and the answer you get is an x value.

@chapter A worked example
@math heading="2x + 3y = 12" items="y = 0:  2x = 12,  x = 6   →  (6, 0)@set y to zero;;x = 0:  3y = 12,  y = 4   →  (0, 4)@set x to zero;;x = 3:  3y = 6,  y = 2   →  (3, 2)@check with x equals three"
Let's graph two x plus three y equals twelve. First, set y to zero. Two x is twelve, so x is six, and the x intercept is six, zero. Now set x to zero. Three y is twelve, so y is four, giving zero, four. Then check with x equals three. Three y is six, so y is two.

@art third-point-check
Three points, six, zero, then zero, four, then three, two, and they're in a line. A line through the origin has both intercepts at zero, zero, so there you take a second point from a table instead.

@art three-misaligned
Why bother with the third? Two points always look consistent, because any two points lie on some line. Only a third point can reveal a mistake. If the three aren't in a line, recheck the arithmetic before you draw anything.

@chapter Two special shapes
@art vertical-horizontal
When one coefficient is zero, a variable drops out, and the line runs parallel to an axis. x equals a is every point with that x, whatever y is. That's a vertical line. y equals b is a horizontal line.

@words text="x = −2 is a line, not a point"
With only one variable, x equals minus two was a single answer. With a second variable present, y is free, and the solution set is a whole vertical line. Keep this shape in mind. It's the one that fails the test in What a Function Is.

@chapter Where people slip
@list heading="Common slips" items="Zeroing the wrong variable@The first|Drawing through only two points@The second|Reading x = −2 as a point@The third"
The first slip is zeroing the wrong variable. For the x intercept, you set y to zero. The second is drawing the line through only two points, which can never show an error. The third is reading x equals minus two as a single point, when it's a vertical line.

@chapter Try it
@words text="3x − 2y = 12" sub="x-intercept given: (4, 0)"
Now you try. Graph three x minus two y equals twelve. You're given the x intercept, four, zero. Find the y intercept. Then pick a third input that isn't zero or four, check all three pairs in the original equation, and only then draw the line.
